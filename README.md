# ZephyrForge

Creates configurable workflows for DevOps teams to track and manage open-source software builds on GitHub and GitLab.

With ZephyrForge, you get a lightweight tool that stays out of your way.

**What you get**

- Creates configurable workflows for DevOps
- teams to track and manage
- open-source software builds on GitHub

## Key Features

- Creates configurable workflows for DevOps
- teams to track and manage
- open-source software builds on GitHub

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/ZephyrForge.git`
2. `cd ZephyrForge`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure ZephyrForge, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
